CSCI-5250 Project: APA 7 Website Theme

As part of a class project, I was tasked with creating a website theme loosely based on the 7th edition of the Amercan Psychological Association's style guidleines. Though a long process, the results of that assignment led to the website you are currently viewing.


The concept of the project started with three core requirements:

  1. To meet user expectations, This CSS theme will prioritize readability, clear information hierarchy, and APA 7-aligned formatting, using accessible font choices, proper spacing, and consistent typography to ensure content is easy to consume. The layout will support standard academic website sections (e.g., CV, research, bio, contact), using responsive design and semantic HTML to ensure usability across devices and assistive technologies. Visually, the theme will adopt APA's minimalist aesthetic while ensuring sufficient color contrast and offering both light and dark modes to meet accessibility standards and user preferences. To support users with minimal technical experience, I will attempt to make the theme “plug-and-play”. Finally, the theme will include built-in support for APA 7 citation and reference formatting, along with optional styles for block quotes, figures, and tables, reinforcing the academic credibility of the site.

  2. The primary users are academic professionals (e.g., psychology faculty, graduate students) with varying levels of technical experience. Many users will have minimal web development knowledge, so the theme must be easy to implement, customize, and maintain without requiring advanced coding skills. Should also be accessible, meeting at least WCAG AA standards for color contrast and keyboard navigation.

  3. The theme must be visually clean, lightweight, and load quickly. It must prioritize accessibility, readability, and aesthetic consistency aligned with APA 7. The project must work across modern browsers (Chrome, Firefox, Safari, Edge) and support desktop and mobile platforms. Since it's a CSS theme, it should be memory-efficient and have no significant processing demands. Networking is minimal or non-existent, as the theme is designed for static websites. There are no external dependencies beyond standard HTML and CSS, which helps ensure broad compatibility and fast load times.

User Study 1

This study developed two functioning prototypes of online academic portfolios, styled to meet style guidelines set by the 7th Publication Manual of the APA (2020), that differ in their display functionality to determine what a focus-group of academics believed to be better.

There was no significant preference for one website over the other (see left). This was not surprising, however, as the design of the two websites were identical except for the primary navigation function. Participants took longer to complete four timed tasks on one version of the website (see right), 3 of those were significantly different at a p < 0.001 using t-test comparisons.

User Study 2

This study compared the preferred website version from the previous study to an existing academic's personal website. The aim of this study was to determine if standardization of the site was preferred by participants, as compared to an unstandardized one. All information on each website was made to be identiacal.

Participants in this sample had a significantly greater liking towards the standardized website [t(10) = -18.472, p < 0.001], see the left figure. They also took significantly less time to complete 4 timed tasks on the standardized compared to the existing website (see right).
